## 5. www-SSL через Cloudflare

- GitHub-cert для www завис на 2 недели (`state:new`), apex работал. Re-add не помог.
- **Решение — Cloudflare.** Аслан завёл аккаунт + дал 2 NS (`jasper`/`rihana.ns.cloudflare.com`).
- Я сменил NS на reg.ru через API (логин `aslanoff`, PFX-сертификат). Аслан включил proxy (оранжевое облако) + SSL Full.
- **Результат:** Cloudflare Universal SSL (Google Trust Services, SAN `dpfsd.ru` + `*.dpfsd.ru`) покрыл apex+www. `www.dpfsd.ru` → 301 на apex, ssl_verify=0. **Починено.** DNS теперь на Cloudflare (reg.ru — только регистратор).
